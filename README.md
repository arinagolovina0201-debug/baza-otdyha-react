# База отдыха «Сосновый берег»

React + TypeScript сайт на Vite. В интерфейсе используются Tailwind CSS и компоненты shadcn/ui.

## Запуск в VS Code

Открой папку `baza-otdyha-react` в VS Code и выполни в терминале:

```powershell
npm install
npm run dev
```

Открой адрес Vite, который появится в терминале (обычно `http://localhost:5173`). Чтобы остановить сайт, нажми `Ctrl+C` в терминале.

Страницы: `/` — главная, `/houses` — дома, `/gallery` — галерея и контакты.
